# 🔍 Code Checker

Анализатор Python-кода. Находит **5 критичных проблем**, которые могут привести к:
- Утечке секретов
- Падению кода
- Взлому через SQL-инъекции
- Выполнению чужого кода

## Что проверяет

- 🔴 **Хардкод секретов** — ключи, пароли, токены в коде
- 🔴 **Голый `except:`** — ловит всё, включая `KeyboardInterrupt`
- 🔴 **SQL-инъекции** — f-строки и конкатенация в SQL
- 🔴 **`eval()` / `exec()`** на данных — выполнение чужого кода
- 🟡 **Опасные вызовы без `try/except`** — `requests`, `httpx`, `open`

## Как запустить

    python checker.py <файл.py>

Пример:

    python checker.py my_code.py

## Пример вывода

    ============================================================
    Анализ файла: my_code.py
    ============================================================

    Найдено проблем: 6

    🔴 Строка 9: Хардкод API-ключ в коде — вынеси в .env
    🔴 Строка 10: Хардкод Пароль в коде — вынеси в .env
    🔴 Строка 17: Голый `except:` — ловит ВСЁ. Укажи тип ошибки.
    🔴 Строка 25: SQL через f-строку — используй параметры запроса
    🔴 Строка 31: `eval()` на не-константе — опасно.
    🟡 Строка 36: `requests.get()` без try/except — может упасть
